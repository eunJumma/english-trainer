단계 다시 공부

단계를 누르면 10단어씩 묶음이 나와요. 원하는 묶음을 골라 다시 풀어요. 이미 지운 단어까지 나오고, 복습은 기록(지운 단어 수)을 바꾸지 않아요.

문법별 연습

원하는 문법이 들어간 문장만 10문항 풀어요. '모두 섞기'를 누르면 여러 문법이 골고루 섞여 나와요. 지금 공부 중인 단계의 단어로 나오고, 기록은 바뀌지 않아요.

이렇게 훈련해요

  1. 어휘 훈련 — 빈칸에 들어갈 단어의 원형을 보기 4개 중에서 골라요.
  2. 문법 훈련 — 고른 단어를 문장에 맞게 바꿔서 직접 써요. 시제, 주어, 단수·복수, 비교급에 맞춰요.
    예) Kate ( cry ) at sad movies. → cries
  3. 지우기 — 두 단계를 각각 10초 안에 맞히면 통과예요. 다른 형태의 문장(cries 다음엔 cried처럼)에서 한 번 더 통과하면 그 단어가 목록에서 지워져요. 형태가 바뀌지 않는 단어(although, among 등)는 다른 문장에서 한 번 더 통과하면 지워져요. 틀려도 괜찮아요. 조금 뒤에 다시 나와요.

여기서 다시 풀어도 기록(지운 단어 등)은 바뀌지 않아요. 보는 동안 지금 문제의 시간은 멈춰 있어요.
